# ADR-007：Hub 专用静态构建与独立维度查询

状态：采用，P2。

前端仓库保留上游普通构建。`MIHOMOHUB_BUILD=true` 才启用服务端实例注册中心、同源空 Secret Endpoint 和 SQLite 历史页面。现有连接、规则、策略、日志页面继续使用 XD 的 API、WebSocket 和按 Endpoint 分离的缓存。

P1 只持久化各维度独立聚合，没有设备 × 域名 × 代理的联合历史维度。连接摘要保存生命周期总量，不能用于重建任意窗口的联合流量。P2 因此展示五种独立 TOP、趋势、覆盖率、缺口及分页连接摘要；不提供可能产生错误统计的跨维度钻取。若未来需要钻取，应先设计联合维度保留与窗口差分，另做数据库迁移和容量验证。

Hub 构建关闭 PWA，使用随前端仓库发布的 Ubuntu Latin 字体（Ubuntu Font Licence）；中文等文字使用现有系统字体回退。旧浏览器 Endpoint 仅显式提示保留/清除，不上传 Secret，也不混算 IndexedDB 历史。新采样不再写入浏览器流量数据库。

历史筛选采用 UTC 完整分钟/小时边界。切换范围立即清空结果，AbortController 加请求代次双重防护阻止迟到响应。没有采样的趋势桶显示空白；恢复候选量不加到观测总量。时间覆盖率不等于归因准确率。
